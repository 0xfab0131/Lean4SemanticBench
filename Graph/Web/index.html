ℓ は中心からの最長導出鎖の長さ
左の一覧: ▾ で枝を畳む。線は枝の範囲、藍の線は中心か選択を含む枝、 色のレールは名前空間。上端に固定される見出しを押すとそこへ戻る。薄い字は名前空間、濃い字が宣言名。
派生: 由来（構造体・構成子・定義）から Lean が機械的に作る宣言（casesOn / mk.inj / sizeOf_spec / eq_1 …）。 既定では由来の行とグラフの節点に畳み、辺には「単射性」等の経由の札を付ける。 グラフの札 ◇k は「この中心から見える派生の数」（0 なら薄い。開いても図は変わらず、一覧で見る）、 ◆n は開いている、藍の ◆n は固定で開いている（中心が派生、または経路表示の区間に派生があるとき。押しても閉じない）。 ノードの外の +n は別物で、深さの先に隠れている依存の数（押すと展開）。 一覧の「派生を全て開く」は全ての由来を開く／畳む操作で、個別の開閉と同じ集合を動かす。
断片: 証明・本体から切り出された補助（_proof_1 / match_1）。由来に埋め戻し、節点には出さない。 骨組み: 論理結合子（And.intro / Eq.mpr）。「表示 ▾」で通り抜けを切り替える。
経路: 極小元のチップや公理のチップを押すと、中心からそこへ至る順序区間 [t, c] = ↑t ∩ ↓c を 元の依存グラフで取り、区間に含まれる派生の由来を自動で開いて強調する（畳んだ派生の中だけを通る経路でも反応する）。
パッケージ: 対象の外の宣言は縁の色で出どころ（Mathlib cslib core …）を示す。凡例はグラフ左上。 「束ね」で「パッケージ」を選ぶと上の錐がパッケージごとの扇になる。右パネルの 📘 docs は公式ドキュメントの宣言ページへ直接飛ぶ。
右パネル: 主語は一つ（「追従」なら選択中の宣言、「中心固定」ならグラフの中心）。 依存・参照のタブもその宣言について出す。中央の見出しは常にグラフの中心。 見た宣言の履歴は ‹ › と [ ] で戻る／進む。チップを押すとその宣言を見てグラフで選択する。 「原文」はソースの宣言範囲そのもの、「型（Lean の表示）」は Lean が整形した型。凡例（グラフ左上）は指すと展開。 枠付きのものは押せる（docs・公理・由来・派生・↗）、平らな札は押せない。導出図では前提の名前を押すとその場で開閉し、 行末の ↗ でその宣言へ移る（‹ で戻れる）。語彙の札は、クリックでグラフの経路を強調、ダブルクリックでプレビューだけ移る。
レポート（上部バー）: 中心／選択／極小元を主語に、主張・型依存・値依存・公理の由来・導出図・極小元・参照・経路・計量・来歴を Markdown で写す。 章「付録: 図」を選ぶと、公理の流入・導出図・境界・経路の Mermaid 図を末尾にまとめる（本文には挟まない）。
